## Aula 2

### `typedef`

Em alguns casos, especialmente quando se está trabalhando com registros, é importante criar tipos de dados próprios. Em C, isso se faz com `typedef`.
A sintaxe de typedef é semelhante à da declaração de uma variável, precedida por `typedef`.

```c
  int a;          // cria uma variável chamada `a` que pode conter dados inteiros
  typedef int t;  // cria um tipo chamado `t`, que é um sinônimo para o tipo `int`
```
Tendo um tipo criado com typedef (na verdade, typedef não cria um novo tipo, cria um novo nome para um tipo), pode-se criar variáveis desse tipo:
```c
  t b;            // cria uma variável chamada `b` que pode conter dados do tipo `t` (ou int)
```
Com os tipos básicos da linguagem, o uso de typedef é um pouco limitado, ele é mais usado com `structs`:
```c
  typedef struct {
      float x;
      float y;
  } ponto;

  float distância(ponto a, ponto b)
  {
      return srqt(quadrado(a.x - b.x) + quadrado(a.y - b.y));
  }

  // fica mais claro que
  float distância(float x1, float y1, float x2, float y2) {...}
```
Com etiquetas nos registros, pode-se separar o typedef da declaração do registro:
```c
  typedef struct ponto ponto;   // define `ponto` como sinônimo para `struct ponto`

  struct ponto {
      float x;
      float y;
  };
```
Usaremos essa separação para ocultar a implementação de um registro do uso desse mesmo registro, algo que será importante na implementação de tipos abstratdos de dados (o primeiro assunto da disciplina depois da revisão).

### referências, ponteiros, structs

Em C (e na maioria das outras linguagens), uma variável declarada em uma função é local a essa função, não sendo possível acessá-la em outra função.
Para que outra função tenha acesso a alguma variável externa a ela, esse valor deve ser passado como parâmetro.
Isso é importante para a organização de programas e a sanidade de programadores.

Em C, quando o valor de uma variável é passado para uma função, essa função só tem acesso ao valor, não tem acessa à variável que contém esse valor.
Além disso, em C, uma função, apesar de poder receber um número qualquer de parâmetros, só pode retornar um único valor para a função chamadora.
Em alguns casos, essa combinação é muito limitante.
Para quebrar essa limitação, é possível obter-se uma *referência* para uma variável. À partir de uma referência, pode-se acessar o valor da variável e também pode-se alterar esse valor.
Uma função pode passar como argumento para outra função uma referência a uma variável sua, permitindo dessa forma que a função chamada possa alterar essa sua variável.

Para poder operar uma referência, necessitamos que o valor dessa referência seja colocado em uma variável, e a partir dela se consegue acessar a variável referenciada (essa operação tem o belíssimo nome de dereferenciação). Uma variável que pode conter uma referência é chamada de `ponteiro`. Para cada tipo de dados "t" de C, existe um outro, "ponteiro para dados do tipo t", que serve para conter referências à dados do tipo "t".

```c
  int a, b;     // declara duas variáveis do tipo int
  int *p;       // declara uma variável do tipo ponteiro para int
  p = &a;       // atribui ao ponteiro p uma referência à variável a
  a = 10;       // atribui um valor inteiro à variável a
  b = *p;       // dereferencia p, e atribui o valor referenciado por p à variável b
  *p = 27;      // dereferencia p, e atribui à variável referenciada por p o valor 27
```
Não é muito complicado, mas tem um perigo: não se pode dereferenciar um ponteiro que não contenha referência para uma variável válida, e isso não é verificável em todos os casos pelo compilador.

#### Ponteiros e registros

Pode-se ter ponteiros para registros, do mesmo modo que para inteiros:
```c
  ponto a, b;   // declara duas variáveis do tipo ponto
  ponto *p;     // declara uma variável do tipo ponteiro para ponto
  p = &a;       // atribui ao ponteiro p uma referência à variável a
  a.x = 10;     // atribui valores à variável a
  a.y = 15;
  a = (ponto){10,15}; // forma alternativa de atribuir um registro
  b = *p;       // dereferencia p, e atribui o valor referenciado por p à variável b
  *p = (ponto){27,5}; // dereferencia p, e atribui à variável referenciada por p o valor <27,5>
```
Até aí muito parecido. Mas quando se quer acessar um campo de um registro apontado por um ponteiro, tem-se um probleminha:
```c
  typedef struct {
      int x;
      int *q;
  } coisa;
  coisa a;
  int b;
  coisa *p;
  p = &a;
  a.x = 30;    // inicializa o campo x do registro a com o valor 30
  a.q = &b;    // inicializa o campo q do registro a com uma referência a variável b
  *a.q = 20;   // altera o valor de b dereferenciando o ponteiro q do registro a
  *p.x = 20;   // dereferencia p para obter a, e altera o campo x de a para o valor 20
```
O problema é que as duas últimas linhas fazem coisas bem diferentes, e têm a mesma sintaxe.
Tem dois operadores sendo usados, o `*` para dereferenciar um ponteiro e o `.` para acessar um campo de um registro.
No primeiro caso, o operador `.` opera antes do `*`, seria equivalente a `*(a.q) = 20;`.
No segundo caso, o operador `*` opera antes do `.`, seria equivalente a `(*p).x = 20;`.
A linguagem C define que o operador `.` tem maior precedência que o operador `*`, então a segunda interpretação não é possível, a última linha do exemplo acima está errada (e vai produzir um erro de compilação não muito óbvio).

As duas operações são comuns (dereferenciar um ponteiro que está em um registro e acessar um campo de um registro apontado por um ponteiro).
Para evitar o problema e diminuir a quantidade de parênteses digitados, foi definido um operador para o último caso, `->`.
Os dois comandos abaixo são equivalentes:
```c
  (*p).x = 20;
  p->x = 20;
```

#### ponteiros e vetores

Em C os vetores não são considerados cidadãos de primeira linha. Por exemplo, diferentemente dos demais tipos de dados,
- não se pode atribuir um vetor a outro;
- não se pode passar um vetor como parâmetro de uma função;
- não se pode ter um ponteiro para um vetor.

Na última versão da linguagem, começaram a retirar (de leve, mantendo compatibilidade) algumas dessas restrições, mas dificilmente retirarão todas.

Para a atribuição de vetores, devemos copiar elemento por elemento, em um laço, ou usar uma função de cópia de memória.

Para as demais, usa-se ponteiros para elementos do vetor.

O nome do vetor, quando usado sem os colchetes, representa uma referência ao primeiro elemento do vetor.
Por exemplo:
```c
  int v[20];
  int *p;
  p = &v[0];
  *p = 20;   // atribui 20 a v[0]
  p = v;
  *p = 30;   // atribui 30 a v[0]
```

Quando se passa um vetor para uma função (com `f(v)`, por exemplo), se está passando uma referência para o primeiro elemento desse vetor.
A função `f` nesse caso pode ser declarada tanto como `void f(int q[])` ou `void f(int *q)`. A declaração de um parâmetro de uma função como vetor é diferente da declaração de uma variável normal como vetor. No caso de um parâmetro, ele será declarado como ponteiro.

A notação de acesso a um elemento do vetor é uma forma diferente de dereferenciação de um ponteiro.
A expressão `v[i]` faz o mesmo que `*(v+i)`.
Isso usa um tipo especial de aritmética chamado `aritmética de ponteiros`, na qual existem 3 operações:
- soma de um ponteiro com um inteiro — produz um ponteiro, que referencia o dado que está tantas posições além do dado referenciado pelo ponteiro. Se `p` referencia `v[3]`, `p+2` referencia `v[5]`.
- subtração de um inteiro de um ponteiro — se `p` referencia `v[3]`, `p-2` referencia `v[1]`.
- subtração de dois ponteiros — produz um inteiro, que tem o número de dados que cabem entre os dois ponteiros. Se `p` referencia `v[3]` e `q` referencia `v[5]`, `q-p` vale 2.

Essas operações só são válidas se as duas referências referenciarem dados que estão no mesmo vetor ou na mesma região de memória alocada dinamicamente.

Como quando se passa um vetor para uma função se está passando uma referência para o primeiro elemento desse vetor, a função não tem como saber o tamanho do vetor. Esse tamanho tem que ser obtido de alguma forma, ou pelo conteúdo do vetor (como é feito com strings) ou porque é um valor préconhecido ou tem que ser passado como parâmetro.

#### Alocação dinâmica de memória

Essa característica de acesso a vetores através de ponteiros facilita a alocação dinâmica de ponteiros.
Em C a alocação de memória é feita por funções, e não é tipada (a memória alocada pode receber dados de qualquer tipo, desde que caiba na memória alocada).
Isso facilita a implementação de alocação de memória por funções, usando uma interface bastante simples. As funções principais são `malloc` e `free`.

- `malloc` recebe como argumento um número que representa quantos bytes de memória se deseja. A função reserva uma região de memória desse tamanho e retorna uma referência para a primeira posição dessa região. Atribuindo-se essa referência a um ponteiro de determinado tipo, pode-se colocar dados desse tipo nessa região. Esse ponteiro pode ser tratado como um vetor, desde que se tenha alocado memória suficiente. O operador `sizeof` ajuda no cálculo da quantidade de dados a alocar.
Por exemplo,
   ```c
   int *q;
   int v[50];
   q = v;
   // q agora está apontando para o início de uma região que contém 50 ints
   // pode-se acessar os elementos de v à partir de q
   q[25] = 130;

   int *p;
   p = malloc(50 * sizeof(int));  // aloca espaço suficiente para 50 ints
   // p agora está apontando para o início de uma região que contém 50 ints
   // pode-se acessar qualquer dos dados dessa memória à partir de p
   p[25] = 130;
   ```
- `free` recebe como argumento uma referência ao início de uma região de memória que foi alocada dinamicamente, e marca essa região como livre para ser reutilizada.

A função `malloc` pode não encontrar uma região de memória livre do tamanho pedido. Nesse caso, ela retorna o valor `NULL`, que não é uma referência válida. Sempre que se usa `malloc`, tem-se que testar para ver se a alocação foi bem sucedida.

### organização do t1

A organização do programa, como visto em aula, ficou mais ou menos como abaixo.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
  bool terminou;
  int pontos;
  int inimigos_inativos;
  int tiros;
  // ...
} estado_t;

void joga_onda(estado_t *est)
{
  repete enquanto nao terminar a onda {
    processa_teclado(est);
    processa_tempo(est);
    apresenta(est);
  }
}

void joga_partida(estado_t *est)
{
  while (!est->terminou_partida) {
    joga_onda(est);
  }
}

int main()
{
  estado_t estado;
  inicializa_tela();
  inicializa_estado(&estado);
  while (!estado.terminou) {
    joga_partida(&estado);
  }
  desinicializa_tela();
}
```
